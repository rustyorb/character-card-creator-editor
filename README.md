

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and set `LLM_API_KEY` (and optional `LLM_API_BASE`):
   ```bash
   cp .env.example .env
   # Edit .env and set your key and base URL if using a custom provider
   ```
3. Run the app:
   `npm run dev`
